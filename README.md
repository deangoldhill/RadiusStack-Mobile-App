# Android app for RadiusStack
This is an Android app for managing a RadiusStack instance. It supports a self-hosted RadiusStack instance or the free RadiusStack SaaS service.

When you first open the app, it will ask if you want to connect to a real RadiusStack instance or run in demo mode, which will conect to and automatically login to a demo RadiusStack instance for testing.

The app is quite basic and mostly designed for visability like stats and sessions. But you can access the entire console and do just about anything possible in the main webui.

There are 3 pinned tabs; Overview - which is the dashboard page of the selected tenant, Sessions - which is the active session table, Users - which is the users page, and more - in which you can change tenants and access every other page 

# Installation
I wanted to publish this on the Playstore, but google seem to be really against non-profit indaviduals publishing apps because it provides them little to no revenue. Their allegiance is to large companies monetizing apps who can afford to go through the wildly intensive process.

Therefore, I have given up trying to publish on the playstore.

If you wan to use this app, you must download it from the github releases.
